## CSS 顺序问题（重要发现）

Vite 构建会重排同一页面上的多个 `<link rel=stylesheet>`（index/rookie 页被反转、mirage 正常，
顺序不可预测），会推翻「公共层在前、页面层在后」的覆盖规则。解法：每个页面 CSS 第一行
`@import url("common.css")`，HTML 每页只留一条 `<link>`（12 个页面已批量改，含注释说明）。
构建后验证：dist 的 rookie CSS 58.5KB = common(29.9) + rookie(28.6)，公共层在前 ✓。
