## 导航下拉改为「树状」HUD 风格（按用户示意图）

- 需求：①子选项去背景；②子项文字与选项文字左对齐；③hover 时呈现「■选项 + 竖线 + 横线·方点」的树状结构；④方点与线条做丝滑生长动画。

- **几何常量（改一个必须一起改，注释里写了推导链）**：
  文字左缘 40px（选项与子项共用）｜方块 left 20px 6×6（中心 23）｜下拉 left 20px｜竖线 left 3px（=23−20）｜横线 left 3px 宽 9px｜方点 left 12px 3×3｜子项文字 padding-left 20px → 绝对 40px ✓

## 搜索功能改为「点击 → 视口中央线框搜索框 + 全场景高斯模糊」

- 需求：点击导航放大镜 → 网页中心出现**线框、无背景**的搜索框，同时整场景高斯模糊玻璃效果。
- **旧实现整体拆除**：`.search-item > .search-trigger + .search-panel#site-search-panel > form.nav-search`（hover 展开、absolute 贴导航下缘、带 surface 底与投影）。common.css 里对应规则全删，断点/reduced-motion 里的残留（1150 的 `.search-panel` 延迟、600 的 padding 与 `.nav-search input`、08 区的 `.search-panel`）一并清掉。
- **弹层必须挂 `<body>` 直接子级**（不是导航栏里）：`.site-header` 带 `transform`（滚动显隐靠 translateY），transform 会成为 `position: fixed` 后代的包含块，弹层留在导航里时 `inset: 0` 只解析出导航条那 80px 高。这是本次最关键的一条。
- **backdrop-filter 与祖先无关**：它模糊的是元素背后的一切，所以放 body 层依然盖住整站。`blur(18px) saturate(125%)`（saturate 补饱和度，避免模糊后发灰）。
- **底纱用 `--page-bg` 派生**：`color-mix(in srgb, var(--page-bg) 42%, transparent)`——浅色主题是半透明白纱，深色主题是半透明黑纱，一套写法两个主题都成立。不支持 backdrop-filter 时 `@supports not` 把浓度加到 88% 兜底。
- **开合机制**：`hidden` 属性 + `.is-open` 类。必须先写 `.search-overlay[hidden] { display: none }`，否则 `display: grid` 会盖掉 hidden。JS 里 `overlay.hidden = false` → `void overlay.offsetWidth`（强制一次 reflow，让 opacity:0 成为过渡起点，否则浏览器合并两次样式改动、淡入消失）→ 加 `.is-open`。关闭时先摘类，240ms（与 CSS 过渡时长对齐）后才 `hidden = true`，否则退场动画被掐断；`closeTimer` 要在 open 时 clear 掉，防止连点被延时隐藏。
- **交互清单**：trigger 点击 toggle；弹层 `mousedown` 且落点不在 `.search-overlay-form` 内 → 关（用 `closest` 而非 `target === overlay`，点提示文字也能关）；Esc 关（监听挂 document，防止焦点跑出去收不到）；右上角 `.search-overlay-close`（内联 SVG ×，currentColor 自动换色）；Tab 焦点陷阱（Shift+Tab / Tab 在首尾环绕）；`body.search-open { overflow: hidden }` 锁背景滚动；开关时同步 `aria-expanded`。
- **焦点归还**：打开时记 `document.activeElement`，关闭时立刻还回去（焦点不能留在即将隐藏的元素里），并判 `document.contains` 兜底。open 时还会先 `ensureHeaderVisible()`——导航若正处收起态带 `inert`，焦点还不回触发按钮。
- **提交**：站内暂无搜索后端，`form action="#"` 时 `preventDefault` + 关闭，避免跳 `#` 把页面滚到顶。
- **联动修正**：`initStickyHeader` 的 `hasOpenPanel()` 里 `.search-item:focus-within / :hover > .search-panel` 已不存在，改查 `document.body.classList.contains("search-open")`，否则弹层打开时导航会被滚走。
- **站点结构**：12 个页面（index / guides×3 / media×1 / servicemaps×7）全部改写——导航里只留 `.search-trigger`（`aria-controls="site-search-overlay"` + `aria-expanded="false"`），弹层插在 `</body>` 前。图标相对路径按层级生成（`./` `../` `../../`），已逐行核对。
- 校验：`node --check` 通过；旧选择器 `search-item / nav-search / search-panel` 全站残留 0；12 页 trigger/overlay 各 1、位置均在 `</header>` 之后；common.css 108/108、index.css 24/24、rookie-guides.css 291/291、map-guides.css 12/12 平衡；HTTP 冒烟 10 条 URL 全 200。
- 遗留：`.map-item` 的 `data-map` 按钮仍无 JS，点击地图图标不跳转。
